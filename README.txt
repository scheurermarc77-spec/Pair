PAIR Demo-Webshop
=================

Dateien:
- index.html     Hauptseite
- styles.css     Gestaltung
- script.js      Warenkorb-Funktion
- manifest.json  Grundlage für Installation als Web-App

Start:
1. Alle Dateien in denselben Ordner hochladen.
2. index.html öffnen bzw. über einen Webserver bereitstellen.

Hinweis:
Der Warenkorb funktioniert lokal. Eine echte Bestellung/Zahlung ist absichtlich noch nicht angebunden.
