PAIR Demo-Webshop – mit Logo
============================

Dateien:
- index.html      Hauptseite
- styles.css      Gestaltung
- script.js       Warenkorb-Funktion
- logo.svg        PAIR-Logo für Kopf- und Fussbereich
- icon-192.png    App-/Browser-Icon
- icon-512.png    App-Icon
- manifest.json   Grundlage für Installation als Web-App

Start:
1. Den Inhalt dieses Ordners vollständig auf deinen Webserver / GitHub hochladen.
2. index.html als Startseite verwenden.
3. Wichtig: Alle Dateien müssen im selben Ordner bleiben.

Hinweis:
Der Warenkorb funktioniert als Demo. Eine echte Zahlung/Bestellung ist noch nicht angebunden.
